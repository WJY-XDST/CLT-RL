# 主动关节目标角与隐式 PD 控制改造和验证

更新日期：2026 年 10 月 11 日。当前平地任务改为直接输出四个主动髋关节的目标角，轮子仍输出目标轮速。环境使用 PhysX 隐式关节 PD，并按用户要求保留下位机标定的重力前馈。旧虚拟腿 PD 与逆运动学不参与新动作的执行；新动作和观测含义改变，必须重新初始化策略，不能直接续训旧权重。

本轮只做有时长上限的执行器验证和 PPO 接口检查，长时间训练保持暂停。没有连接实车，没有删除旧模型，也没有把本轮短测解释为训练收敛。

## 策略输出和执行链

每条腿有两个主动髋关节，不是一个主动髋关节加一个主动膝关节。实际 articulation 的四个主动关节顺序为 `LB_joint、LL_joint、RB_joint、RL_joint`；被动闭链关节不由策略直接控制。

| 动作索引 | 新动作含义 | 实际控制关节 |
| --- | --- | --- |
| 0 | 左腿 B 主动关节目标角 | LB_joint |
| 1 | 左腿 L 主动关节目标角 | LL_joint |
| 2 | 左轮前进为正的目标轮速 | LW_joint |
| 3 | 右腿 B 主动关节目标角 | RB_joint |
| 4 | 右腿 L 主动关节目标角 | RL_joint |
| 5 | 右轮前进为正的目标轮速 | RW_joint |

PPO 的 actor 仍参数化高斯策略：输入 27 维观测，输出 6 维均值并学习探索标准差。训练时采样动作，确定性回放时使用均值。网络保持 `27 → 256 → 128 → 64 → 6`，隐藏层使用 ELU；critic 使用相同隐藏层，末层输出一个状态价值。此次改的是四个腿部输出的含义和环境执行方式，不需要修改第三方 PPO 算法，也没有冻结腿输出或共享特征。

腿部动作映射为：

```text
a = clamp(policy_action[0, 1, 3, 4], -1, 1)
q_ref = q_offset + q_scale * a
q_ref = clamp(q_ref, articulation_lower_limit + margin,
                    articulation_upper_limit - margin)
```

`q_ref` 是原始 CAD 电机关节坐标中的目标角，单位 rad；右腿不再额外乘一次镜像符号。`q_offset` 是固定参考姿态，不跟随高度命令变化。当前零动作对应几何上约 0.30 m 机身高度、零虚拟腿摆角：

| 关节 | q_offset rad | q_scale rad |
| --- | --- | --- |
| LB_joint | −0.0707452938 | 0.30 |
| LL_joint | −0.0336936327 | 0.30 |
| RB_joint | +0.0707452938 | 0.30 |
| RL_joint | +0.0336936327 | 0.30 |

`q_scale=0.30 rad` 是训练动作幅度，不是电机硬件角度上限。`margin=0.01 rad` 是模型关节边界内的数值保护余量，不是下位机给出的机械行程。高度命令只作为策略输入和奖励目标，策略必须学习如何改变关节角来跟踪高度；没有隐藏的 IK、高度反馈或腿长混合控制替策略完成这个任务。

四个腿关节的位置和速度目标送入隐式 drive。其反馈模型可写为 `Kp*(q_ref−q) + Kd*(0−q_dot)`，实际反馈由 PhysX 内部隐式求解，不由环境手工计算后下发。当前 Kp 为 300 N·m/rad、Kd 为 3 N·m·s/rad；它们是沿用的仿真控制增益，不是已在下位机部署的主动关节 PD 标定。

轮子控制不变：动作乘 15 rad/s，原始关节坐标的左右轮符号为 `[+1, −1]`，隐式速度 drive 的 damping 为 0.5 N·m·s/rad。15 rad/s 同样是训练参考尺度，不是已确认的电机额定转速。

## 重力前馈和总力矩限幅

`leg_joint_gravity_feedforward=True` 保留原下位机对应的补偿：单腿基础力为 `6.17×9.81=60.5277 N`，按机身 pitch、实际虚拟腿角和既有坐标偏置进行余弦补偿，再限幅到 ±150 N。采用实际五连杆 Jacobian 映射为四个主动关节的前馈力矩：

```text
tau_gravity = J.transpose @ [F_gravity, 0]
tau_total   = implicit_joint_PD + tau_gravity
```

第二个虚拟广义力矩分量为零，不叠加旧摆角 PD；第一个分量只有重力补偿，不叠加旧腿长 PD。不加入气弹簧前馈。前馈走 `set_joint_effort_target()`，关节目标角保持原样，不把前馈偷偷换算成角度偏置。

普通 drive 的 `maxForce` 不能直接当作“PD 加外部前馈”的总限幅。当前四个主动关节在克隆之前应用 `PhysxDrivePerformanceEnvelopeAPI:angular`，使用已有力矩上限及默认的无速度降额参数，让物理引擎约束隐式 drive 与外部关节前馈的总和；不能应用该接口时立即报错。没有编造电机转矩转速曲线，也不在每个物理步通过 CPU 改写 drive 力矩上限。[NVIDIA 对该总力矩约束的定义](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/107.3/dev_guide/joints/physx_joint_schema.html#physxdriveperformanceenvelopeapi)。

限幅依据是下位机外层 `MDK-ARM/project_h7.uvprojx` 实际引用的源文件，不使用工程中更老的嵌套副本：

| 物理量 | 已确认限幅或标定 | 下位机依据 |
| --- | --- | --- |
| 腿关节输出轴命令力矩 | ±35.574 N·m | LK_motor.c 的 `(torque/1.078)*2048/33`，输出裁剪到 ±2048 |
| 轮关节命令力矩 | ±4.80944 N·m | torque.c 的最终 ±16000 CAN 限幅，乘 torque.h 的 0.00030059 |
| 单腿重力前馈径向力 | ±150 N | torque.c 的 F0_control |
| MG8016-i6 主动关节安全角度范围 | 该力矩控制路径未明确给出 | 编码器绕回范围不是机械行程 |
| 腿与轮的额定输出轴转速上限 | 该力矩控制路径未明确给出 | 恢复动作的转速指令不是电机额定上限 |

35.574 N·m 是用户实车标定对应的命令满量程，不等于已核实的持续额定力矩。减速比不再重复乘到关节力矩上；轮子上游 `torque_sen=0.3` 也不再乘到最终 CAN 物理限幅上。其他电机 DM MIT 协议的角度或转速编码范围不套给 MG8016-i6。

下位机空中状态的 `F0` ±120 N 是旧 VMC 总径向力的条件裁剪，不是电机关节力矩上限，也不是普通地面重力前馈的 ±150 N。新关节 PD 模式没有同名的“总虚拟径向力”控制输出，因此没有把 120 错用为 N·m 上限。

尚未明确的角度和转速硬件边界在 `MCU_LIMIT_EVIDENCE` 中记为 `None`。仿真保留当前 CAD 的闭链和机械止挡保护，但不宣称这些边界已由下位机参数确认。实际部署前需要补齐硬件范围并核对对应坐标；当前仅验证仿真。

## 观测和奖励调整

观测总维数保持 27，但腿部 8 维改为四个主动关节的位置和速度，旧权重即使网络尺寸相同也不兼容。

| 索引切片 | 内容 | 缩放 |
| --- | --- | --- |
| 0:3 | 机身角速度 | 0.25 |
| 3:6 | 机身坐标下投影重力 | 1 |
| 6:9 | 前进速度、yaw rate、机身高度命令 | 2、0.25、5 |
| 9:13 | LB、LL、RB、RL 的实际角度减固定 q_offset | 1 |
| 13:17 | 同顺序的四个实际关节角速度 | 0.05 |
| 17:19 | 去除 yaw 后的机身水平 X、Y 线速度 | 2 |
| 19:21 | 左右轮前进为正的实际角速度 | 0.05 |
| 21:27 | 上一物理执行动作的归一化值 | 1 |

9:13 是相对固定参考姿态的角度，不是相对当前策略目标角的误差。目标角、实际角、前馈力矩分别记录；FK 推导的实际腿长和摆角仍用于物理诊断及既有状态奖励，不再用于把动作解释为虚拟腿目标。

关闭三项依赖旧 action[1]/action[4] 腿长含义的奖励：`leg_length_action_saturation`、`leg_length_action_difference`、`leg_length_target_underreach`。新增四个主动关节动作的软饱和惩罚，按未经执行裁剪的动作计算 `sum(relu(abs(a)−0.85)^2)`，权重 −5，按控制周期计入奖励。速度、机身高度、姿态、实际摆角、接触安全等既有奖励保留；不强制两腿实际长度相等。

重置同时清理动作历史、关节目标、前馈缓冲和外部努力，避免上一回合的饱和目标残留。第一次物理控制更新重新计算当前姿态的重力前馈。

## 模型资产和训练兼容性

默认资产同步为最近实际运行使用的 `mine_closed_chain_training_protected_stops_v2.usd`，闭链被动关节匹配改为 `[LR]L[123]_joint` 和 `[LR]L3_[LR]S_closure`，保留自碰撞、128 次位置求解和 8 次速度求解。它们原本已存在于最近训练的启动覆盖参数中，本次没有改 CAD 杆长、惯量、铰链坐标或闭链拓扑。

物理周期仍为 5 ms，策略周期仍为 20 ms；8192 个并行环境、25% 固定站立身份及原课程配置保留。有限验证临时覆盖为 1、4 或 16 个环境，不改变下一次正式训练默认数量。

训练、回放和评估增加模式与动作映射检查；旧的 `explicit_vmc` 或 `implicit_joint_reference` 权重不能按新模式直接加载。新的输出目录为 `IsaacLab/logs/rsl_rl/mine_wheel_legged_joint_pd_flat/`，每次保存 joint mapping、重力前馈开关和硬件限幅来源。旧模型和暂停标记保留。

跳跃任务仍使用其原有虚拟腿接口，本次没有改成直接关节策略。现有 MuJoCo 和实车部署接口也不能直接套用这份新动作定义；需要另行同步观测、目标角、PD 与前馈，不能只换权重。

## 本轮验证

CPU 回归已通过 267 项，包含动作映射、机械边界裁剪、四个主动关节的观测顺序、左右坐标、重力前馈独立通道、旧权重拒绝、实际下位机限幅来源和全工程既有测试。61×61 的两主动角采样网格通过闭链几何有效性检查；这不等于全部动态工况都已通过。

零重力固定根节点测试的首轮因投影重力为零触发跌倒终止，数据保留为失败测试，不能用于跟踪结论。仅在该诊断中把重力跌倒计时推迟到测试结束之后，其他终止条件和生产代码不变；复测 10 s 无重置，正、负 0.045 rad 目标阶跃及恢复零动作的最大末段误差均小于 0.000006 rad。这一复测是加入总限幅接口之前的纯 PD 基线，不能替代最终 PD 加前馈版本的验证。

最终版本的 GPU 验证如下，均有运行时长和内存上限，结束后退出，没有恢复后台长训：

| 验证 | 结果 | 可以得出的结论 |
| --- | --- | --- |
| 加入总力矩限幅接口后的四环境零重力阶跃，10 s | 0 次重置，最后 1 s 最大关节误差 0.00000622 rad，关节观测块误差 0 | 四个独立主动关节能响应正、负角度指令，观测顺序正确 |
| 真实重力、单环境物理竖直导轨，10 s | 0 次重置，最低根高度 0.2854 m，末段平均高度 0.30194 m | 隐式 PD 与独立重力前馈可以完成本工况的承重、伸缩和恢复 |
| 随机新策略，16 个自由环境，1 个 PPO iteration | 768 个状态转换，完成更新和保存；模型及优化器张量全部有限 | 新 27 维输入、6 维动作、采样和反向传播接口跑通 |

带重力测试按零动作、伸腿、收腿、恢复零动作顺序执行，两个主动关节分别有 ±0.03 rad 目标变化；没有调用旧 VMC 或 IK。末段最大关节误差约 0.00988 rad，重力前馈峰值 8.94 N·m，前馈目标与记录缓冲完全一致。承重时 PD 有静态柔顺误差，不能用零重力测试的微小跟踪误差替代承重结果。

多环境导轨夹具没有通过：把世界关节放在被克隆子树内时出现角度发散；将其移到全局路径后，四环境测试仍有非预期机身接触终止。单环境同控制器和力矩上限通过，后续 16 环境无导轨 PPO 也完成了数值接口检查，但这不足以宣布多环境导轨的所有问题已经定位。因此该脚本现在只允许单环境导轨，四环境仅用于固定根节点关节隔离测试；失败数据保留，不删掉或改写成通过。

补充核对轮执行器时曾把测试缩短为 7 s：末段 1 s 的误差窗口恰好包含 6.02 s 恢复零动作的瞬态，因 0.0100 rad 瞬态误差判为失败；6.5 s 已降至 0.00000223 rad，且没有重置。该记录保留为测试窗口错误，不冒充新的动力学故障。脚本将最短测试时间改为 8 s，保证末段窗口包含稳定时间；按原 10 s 复测通过。最终读回的四个腿 drive 上限为 35.574001 N·m，两个轮 drive 上限为 4.809440 N·m，浮点误差范围内均与下位机来源一致。自动检查必须读取 `assessment.json` 的 `passed` 字段，不只看 SDK 进程的退出状态。

一次 PPO 更新的 value loss 为 6173.0957、surrogate loss 为 −0.0118。这是随机策略的初次接口测试，不是收敛结果；仍出现不安全终止，不能称为“已学会站立”。优化器 17 个参数状态均有非零一阶矩，六个动作输出行全部参与更新，未冻结腿部或共享网络。保存的 `model_0.pt` 只用作接口证据，不推荐部署或代替旧的有效模型。

导轨只允许竖直运动，会约束机身 pitch、roll、平移和 yaw；导轨撑住不代表策略已经学会无导轨平衡。Isaac Lab 的 `applied_torque` 在隐式模式下是估算值，不冒充物理引擎实际 drive 力矩测量。总力矩限幅的接口和配置已核对，但本轮并未通过实机测量验证峰值或持续额定能力。
