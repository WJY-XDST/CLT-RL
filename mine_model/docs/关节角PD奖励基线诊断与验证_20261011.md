# 主动关节角 PD：奖励诊断与从零对照验证

日期：2026-10-11。对象是当前大五连杆闭链机器人，不是旧开源示例车。此次修改只建立一个独立的奖励对照，不改变车辆资产、控制器、物理限幅、观测、PPO 或训练课程。

## 1. 结论和证据边界

已确认两类现象：**策略回放时机身确实撞到地面；旧奖励存在重复速度目标和过早裁剪。** 接触不是仅凭渲染判断，也不是把自碰撞当成地面接触的推测。

这尚不能证明奖励是全部摔倒问题的唯一根因。悬空驱动和竖直导轨支撑已验证执行链，但不等于整车自由平衡。此次保持执行链不变，另开随机权重训练，用独立回放判断奖励精简是否有效；若仍持续早期摔倒，停止该实验继续检查，不能用增加训练次数替代诊断。

## 3. 旧奖励具体有什么问题

### 3.1 相同速度目标叠加五项

零速时，同时启用宽指数、enhance 窄指数、precise 窄指数、前向平方速度误差，以及仅在线速度指令为零时作用的水平速度惩罚。多项奖励本身不是错误，但这里混用了旧 VMC 调参和新主动关节角策略，难以区分哪项在限制行为。

旧 `standing_velocity` 权重为 −50，按通用上限 1 reward/s 裁剪，水平速度模长达到 `sqrt(1/50) ≈ 0.1414 m/s` 后，该项对更大的漂移都给同一个值。旧 `lin_vel_error_sq` 的上限更高，仍能区分前向误差，不能说所有速度反馈都失效。

### 3.2 yaw 平方惩罚过早饱和

旧 `yaw_rate_error_sq = −5 × (ωz − ωz_cmd)²`，单独上限是 1 reward/s。因此误差超过 `sqrt(1/5) ≈ 0.4472 rad/s` 后都得到同一惩罚；上述失败回放大部分已处于这个区间。

这指的是**奖励无法区分较大的误差**，不是 PPO 对物理奖励直接反向传播时“梯度为零”。PPO 更新的是策略概率与价值估计，不能把两者混为一谈。

### 3.3 姿态和终止量级偏重

旧姿态项是 `−150 × (gx² + 4gy²)`，上限 30 reward/s。单独 pitch 约 26.57°、单独 roll 约 12.92° 就达到上限，混合倾斜更早。这里 `g` 是机体系中的单位重力方向，`gx` 主要反映 pitch，`gy` 主要反映 roll，不是角度本身。

旧事故终止一次扣 200，不乘控制周期；理想状态连续正奖励最高约 4 reward/s，200 相当于其 50 s，而 episode 上限为 20 s。这是显著的学习量级选择，但不能仅由此推断策略必然选择倒地。

## 4. 本次改动：独立奖励基线

新增任务 `WheelLeggedJointPD-Flat-v0`，配置类 `MineWheelLeggedJointPDBalanceEnvCfg`，奖励标识 `joint_pd_balance_v1`。原 `WheelLeggedVMC-Flat-v0` 的奖励配置保留，便于对照，不用同名任务悄悄替换旧实验。

| 内容 | 原关节角训练使用的奖励 | 新对照 |
| --- | --- | --- |
| 直线速度跟踪 | 3 个指数项＋平方项＋静止专用项 | 一个宽指数，权重 2；一个水平平方误差，权重 −2 |
| 侧向漂移 | 平方速度主项只看 vx，vy 仅在零线速项中出现 | 所有速度命令下均看 `(vx − vx_cmd)² + vy²` |
| yaw 跟踪 | 指数 1；平方项 −5，上限 1/s | 指数 1；平方项 −1，上限 4/s，至 2 rad/s 才饱和 |
| 高度 | 指数 1＋平方项 −1000 | 单个指数 2，指数宽度仍为 0.0004 m² |
| 通用姿态 | −150，roll 倍率 4 | −20，roll 倍率 2，仍保留 30/s 安全裁剪 |
| 虚拟腿姿态先验 | 左右摆角差 −60，零速绝对摆角 −5 | 此基线关闭；不要求两腿长度相等 |
| 动作约束 | 关节原始动作软饱和 −5，动作一阶／二阶变化项 | 软饱和 −0.5；只保留六维一阶变化 −0.02 |
| 能耗／高频状态正则 | 关节速度、加速度、估计力矩等 | 此基线关闭，避免把隐式驱动力矩估计当作硬件能耗 |
| 非轮部件碰撞／关节越界 | 保留保护 | 各权重 −1；终止条件与碰撞形状不变 |
| 事故终止 | 一次 −200 | 一次 −20；不乘 dt；正常超时不扣此项 |
| 通用逐项奖励上限 | 1/s | 5/s，避免权重 2 的正指数奖励在接近目标时被压平 |

新配置有 11 个非零奖励项，分成 6 项任务目标、2 项动作正则、3 项安全项。不是以“项数越少越好”为目标，而是建立能解释、能对照的起点。

连续项先按下列每秒尺度计算，再乘策略周期 `dt = 0.02 s`：

```text
ev = vx_cmd − vx                       # m/s，yaw 对齐的水平前向速度
eh = z − z_cmd                         # m，当前机身原点高度减目标高度
ew = ωz − ωz_cmd                       # rad/s，机体系 yaw 轴角速度误差

速度指数：      +2 exp(−ev² / 0.25)
水平平方误差：  −2 (ev² + vy²)          # 上限绝对值 8 reward/s
yaw 指数：     +1 exp(−ew² / 0.25)
yaw 平方误差： −1 ew²                  # 上限绝对值 4 reward/s
高度指数：      +2 exp(−eh² / 0.0004)
通用姿态：      −20 (gx² + 2gy²)        # 上限绝对值 30 reward/s

动作一阶变化：  −0.02 Σ(a_applied − a_previous)²
关节动作软限：  −0.5 Σ relu(|a_raw,joint| − 0.85)²
```

`a_raw,joint` 是策略裁剪前的四个关节动作；`a_applied` 是实际送给执行链的六维动作。物理动作仍硬裁剪到 `[-1,1]` 并经过关节目标安全边界。保留软饱和惩罚不代表放开物理限幅。

静止也可能需要非零轮子参考和力矩来平衡。这里没有要求轮子动作等于零，没有强制左右轮相等，没有增加只在静止时禁用补偿的惩罚。恒定非零动作不触发动作变化惩罚。

**对照限制：一次调整了多个奖励变量，验证的是整套精简基线，不是单项权重的因果消融。** 新旧总 reward 量级不同，不能用总 reward 变大作为学习改善的证据。

### 为什么完整验收仍为 False

默认站立的机身任务指标全部通过，完整验收失败项只有 `wheel_speed_mae_rad_s`：这是实际轮速相对于**策略轮速参考**的误差，不是机身速度相对于用户命令的误差。

左轮实际／参考末段均值约为 0.0030／0.5638 rad/s，右轮约为 0.0292／0.0818 rad/s。以当前速度 PD 阻尼 0.5 N·m·s/rad 计算，参考与实际轮速差对应的名义驱动需求约为 0.280／0.026 N·m。非零速度参考可能在速度反馈链中产生保持平衡的力矩；**这是根据控制公式的解释，不是对 PhysX 原生驱动力矩的直接测量**。参考误差单独不能证明轮子卡死，也不能证明该差异在所有工况均合理。

原完整验收门槛及 `passed=False` 原样保留，没有为了通过而提高轮速阈值或删除该指标，更不把站立通过当作 sim2real 准入。后续运动课程需要同时检查机身命令响应、轮速参考、力矩限幅和接触状态。

### 未学习的工况必须继续区分

前进／后退 ±0.3、±0.6 m/s 时实际速度仍接近 0；±0.3 rad/s 转向也基本不响应。高度命令 0.28／0.32 m 时实际高度仍约为 0.2994／0.2981 m，偏差约 19.4／21.9 mm。因此不能宣称运动、转向和变高度已经学会。

现有相对高度门槛为目标高度的 10%，这两个高度案例虽然落在宽容差内，**不代表对高度命令已经有正确响应**。后续必须观察不同目标的实际高度变化，而不是只看一次静态容差是否通过。
