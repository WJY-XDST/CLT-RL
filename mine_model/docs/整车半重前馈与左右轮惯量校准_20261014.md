# 整车半重前馈与左右轮惯量校准

用户明确按下位机设置，并将每条腿的基础重力前馈定义为整车重力的一半。
`mcu_hardware.py` 现明确保存整车名义质量 `12.34 kg`，单腿质量参数为
`12.34 / 2 = 6.17 kg`，基础前馈为 `6.17 × 9.81 = 60.5277 N`。
这次定义澄清没有改变此前已经运行的前馈数值。

`gravity_feedforward()` 继续按下位机倾角、机身 pitch 和固定角度偏置进行余弦补偿，
保留 ±150 N 径向力限幅。直接关节模式仅将该重力前馈通过 `Jᵀ[F,0]`
转换为关节努力，反馈仍由 PhysX 关节位置 PD 产生；策略动作仍直接给四个
主动关节目标角，不添加虚拟腿 PD 或 IK 控制。

原 `model.json` 的 `supported_mass_kg = 9.553` 是历史 CAD 统计，不能代表当前
前馈质量。当前 USD 的十五个刚体质量和约为 `10.8829996 kg`，已包括两轮各
`0.665 kg`；它与下位机前馈采用的整车名义质量 `12.34 kg` 仍有差异。
本次只明确前馈定义和统一两轮惯量，没有把这两种质量宣称为已完全校准一致，
也没有通过任意改写车体质量去掩盖差异。

两侧使用相同轮组，按用户要求统一主惯量。以右轮 CAD 为参考：

| 主惯量 | kg·m² |
| --- | ---: |
| I1 | 0.0005099578993394971 |
| I2 | 0.0005024567944929004 |
| I3 | 0.0007531667943112552 |

将右轮惯量张量在基座坐标镜像，再转换为左轮局部坐标。不能直接照抄局部
主轴四元数，因为两个轮子的局部坐标不同。原生 PhysX 读回两侧转轴惯量均约为
`0.000753152126 kg·m²`，主惯量在浮点精度范围内一致。各刚体质量、质心、
关节坐标和限位、闭链与碰撞几何保留。该惯量仍是 CAD 估计值，未伪称实测。

新增不可覆盖的 `mine_closed_chain_training_matched_wheels_20261014.usda`，
依赖此前轮质量层与原闭链资产。同名 JSON 保存 SHA-256、所有来源及原生核验。
历史资产不覆盖；旧检查点保留配套 USD 以便复现。

工程回归 448 项通过，62 个子测试通过；常规 Python 环境缺少 USD 初始化时跳过
三项，随后在原生 USD 库环境运行该文件的四项检查全部通过。
单环境 PhysX 核验读回实际惯量和质量，10 个控制步的观测、奖励有限，无重置。
此测试只是资产加载核验，不能替代策略跟踪验收。
