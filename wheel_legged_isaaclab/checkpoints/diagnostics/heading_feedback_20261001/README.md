## 初始腿摆角对照

同模型seed53静止5秒，带扰动与零初始速度对照，无重置。带扰动摆角峰值10.49°，进入各腿最终稳态均值±1°约0.78秒、±0.5°约1.02秒；零初始速度分别2.42°、0.24秒、0.64秒。两腿角差进入1°带分别约0.08秒和0秒。这里是仿真时间，收敛基准是各腿最后2秒均值，不是声称对零角度或策略动作目标的跟踪误差。

初始目标腿角也在大幅变化；当前结果不足以归因于VMC刚度不足。暂不调整kp_theta=50、kd_theta=3，后续需同时比较初始摆幅、恢复时间及抗扰稳定性。参见leg_startup_assessment.json和leg_startup_comparison.png。
