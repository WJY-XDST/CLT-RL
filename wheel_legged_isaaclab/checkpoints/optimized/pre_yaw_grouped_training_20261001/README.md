# 分组转向续训前的正式模型备份

本目录封存模型 **5740**。它是当前可视化使用的已验收直行模型，尚未接受新加入的分组转向训练。两次 2 迭代启动检查产生的 5741 均不是该模型。

- `model.pt`：原模型的完整副本，SHA256 与原留存一致。
- `env.yaml`、`agent.yaml`、`original_manifest.json`：该模型原训练配置与代码来源。仓库当前新增的转向课程不能当作此模型已经训练过的内容。
- `assessment.json`：原直行验收报告；`assessment_seed49.json`、`summary_seed49.json`：追加可视化验证。
- `yaw_assessment.json`：首次 11 段转向测试结果，每段后 2 秒统计；`yaw_first_cycle.csv.gz`：2750 行原始测试数据，解压后可复核。
- `yaw_schedule.json`、`yaw_command.json`：44 阶段完整回放计划和实际启动命令（含本机绝对路径）；本目录 CSV 只记录其中最初 11 段。
- `manifest.json`：本次存档时间、代码版本及文件校验值。

## 当前能力与不足

原速度、高度、姿态与腿角差测试已通过；yaw 转向仍未达标。原地左/右转的角速度稳态相对 MAE 为 26.75%/20.60%，前进左/右转为 28.20%/12.56%。原地转时还存在约 0.05–0.06 m/s 的前后漂移。

本目录是后续模型比较及回退的基线，不宣称转向训练完成。读取或播放新模型前应核对对应模型自己的训练配置和验收报告。
