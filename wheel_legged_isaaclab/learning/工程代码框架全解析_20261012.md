## 配置和任务注册

[任务注册](../wheel_legged_gym_isaaclab/tasks/direct/wheel_legged_vmc_flat/__init__.py)将 `WheelLeggedJointPD-Flat-v0`、`WheelLeggedVMC-Flat-v0` 两个保留任务名映射到同一环境、同一配置及同一 PPO 配置。它们是别名，不是两辆车。真正决定执行链的是 `leg_control_mode`，默认 `implicit_joint_position`；显式 VMC 必须指定 `explicit_vmc` 并配对正确权重。

唯一环境配置直接继承 `DirectRLEnvCfg`。同文件的观测、命令、奖励子配置只是功能分组，不是适配子类。`__post_init__` 只增大 GPU 接触缓冲容量，不覆盖车辆或奖励。训练时 `env.*`、`agent.*` 覆盖作用于这份配置，再保存完整运行值。

主环境为 1198 行，命令功能文件为 72 行，配置为 327 行，均包含注释和空行。所有 LAB 回调在主环境，命令功能文件只修改同一实例的缓存。没有四个 Mixin 或 `Mine*EnvCfg` 二次覆盖层。

## 动作执行链

| action 索引 | 直接关节角模式 | 显式 VMC 模式 |
| --- | --- | --- |
| 0、1 | LB、LL 目标角偏移 | 左虚拟腿摆角、长度参考 |
| 2 | 左轮目标角速度 | 左轮目标角速度 |
| 3、4 | RB、RL 目标角偏移 | 右虚拟腿摆角、长度参考 |
| 5 | 右轮目标角速度 | 右轮目标角速度 |

```text
obs → actor → raw action → 环境执行限幅 [-1,1]
  ├→ 四关节 nominal offset + action × scale → 安全目标角
  │    → PhysX 隐式关节 PD + Jᵀ[F_gravity,0] 独立重力前馈
  │    → 总力矩 envelope → 四主动电机
  └→ 两轮 action × 15 rad/s → 隐式速度阻尼驱动
  → PhysX 计算闭链和接触 → 下一帧状态
```

四关节 offset 为 `[-0.0707452938,-0.0336936327,+0.0707452938,+0.0336936327] rad`，尺度各为 `0.30 rad`。目标角与 USD 限位减 `0.01 rad` 裕量取交集。0 action 表示 nominal pose，不是零力矩。腿部 PD 默认 Kp=300、Kd=3，轮阻尼 0.5。

下位机命令限矩为腿 `35.574 N·m`、轮 `4.80944 N·m`，不是持续热额定力矩声明。每腿重力基准 `60.5277 N` 按腿角及 pitch 补偿，径向前馈限制到 `±150 N`，没有气弹簧前馈。

显式 VMC 在同一个 `_apply_action()` 的另一分支中，虚拟摆角和腿长 PD 得到 T/F，加前馈后经 Jacobian 转为四关节力矩，腿内置 PD 为 0/0。直接关节模式也需要 FK/Jacobian 计算状态、前馈和有效性；删除 IK 不等于删除这些数学。

主动角动作范围、USD 独立角限位、CAD 限位块接触、VMC 虚拟腿参考范围是不同约束。直接关节模式不走腿长硬参考裁剪，实际长度由闭链运动决定，不能用 0.250 m 下杆长度作为所有模式的腿长上限。

## 观测和命令

`_get_observations()` 返回 `{"policy": obs}`，形状 `[N,27]`，当前为单帧 MLP，不额外拼五帧输入。

| 切片 | 直接模式字段 | 默认缩放 |
| --- | --- | --- |
| 0:3 | 机体系角速度 xyz | 0.25 |
| 3:6 | 机体系单位重力方向 | 1 |
| 6:9 | 速度、yaw rate、高度命令 | 2、0.25、5 |
| 9:13 | LB LL RB RL 实际角减 offset | 1 |
| 13:17 | 四主动关节角速度 | 0.05 |
| 17:19 | 航向对齐水平机身 vx、vy | 2 |
| 19:21 | 两轮实际转速，前进为正 | 0.05 |
| 21:27 | 上一周期有效执行动作 | 1 |

VMC 的 9:17 改为两侧虚拟摆角、摆角速度、腿长、腿长速度，尺寸相同但语义不同。实际根高度没有单独 obs 列。水平速度从世界 XY 投影，不用轮速乘半径替代；右轮符号只在读写边界转换。轮累计角不输入，轮速仍保留。

此函数也推进命令和动作历史，不是无副作用 getter。调试不要同一步重复调用，应记录真正 actor 输入。

训练默认 8192 个环境，前 2048 个固定零速零 yaw，其余轮换原地转向、前进、后退及两种行进转向，共用一个策略。前 48,000 控制步练站立，再用 48,000 步引入运动、高度和 yaw；按每轮 48 步，两个阶段各约 1000 iterations。续训必须恢复课程时钟。

完整主速度范围为 `0.2～0.8` 和 `-0.8～-0.2 m/s`，低速桥接 `-0.2～0.2 m/s`，yaw `±0.3 rad/s`，高度 `0.28～0.32 m`。运动组约三分之一低速，速度边界比例 0.3、高度边界比例 0.4。

`env_commands.py` 采样终点，`_target_lin_vel_x` 保存终点，观测更新按 `0.8 m/s²` 斜坡推进应用速度，重采样周期 5 秒。误差应相对实际送入策略的命令计算。

只保留分组训练。旧概率采样及 `transition_env_fraction`、`reverse_env_fraction`、`yaw_env_fraction` 已移除；固定速度范围 min=max 供回放使用。读取旧配套配置只去掉当时未生效的字段，真正依赖退役采样方式的配置会明确拒绝。

训练 `heading_command=False`，学习 yaw rate。航向保持是可选外部反馈，不能覆盖训练转向指令；yaw rate 为零并不保证世界 yaw 角永远不变。

## 奖励和安全

默认权重直接在唯一 `RewardsCfg` 中，`_get_rewards()` 计算信号；`reward_signals.py` 只提供数学和日志函数，profile 字符串是版本标识，不再二次改参数。

| 主项 | 默认权重 | 含义 |
| --- | ---: | --- |
| tracking_lin_vel | 2 | 前向速度指数跟踪 |
| lin_vel_error_sq | -2 | 前向误差平方加 vy² |
| tracking_ang_vel | 1 | yaw rate 指数跟踪 |
| yaw_rate_error_sq | -1 | yaw rate 平方误差 |
| base_height | 2 | 根节点高度指数跟踪 |
| orientation | -20 | 投影重力 x² 加两倍 y² |
| action_rate | -0.02 | 有效动作一阶变化平方 |
| joint_position_action_saturation | -0.5 | 四关节 raw action 超过 0.85 的平方代价 |
| collision、dof_pos_limits | 各 -1 | 非轮接触和实际关节越界 |
| termination | -20 | 一次不安全终止，不惩罚超时 |

2097 模型的实际 yaw 平方权重为 -5，来自其配置，不是今天的默认 -1。连续项乘权重和 dt 后裁剪再求和；终止项单独加入。高度指数分母 `0.0004 m²` 对应 20 mm 特征宽度。通用裁剪上限 5，线速度负代价 8、yaw 4、姿态 30，应用时均乘控制 dt。

默认为零的其他信号仍供 VMC 或有记录的单变量对照，不是假装生效的奖励。直接模式不将关节角动作解释为腿长。没有强制两腿等长或两轮动作相等。

`_get_dones()` 独立计时机身/连杆接触、pitch/roll、翻倒、低高度；非有限数和运动学奇异直接记录。安全后清对应计数。机身 10 N 接触约 0.15 s，腿部 5 N 接触约 0.2 s，pitch 超 30° 约 0.25 s，roll 超 20° 约 0.2 s 会终止。净接触力可能包括自碰撞，归因时需过滤地面接触并检查间隙。

## LAB 调度和 PPO 库

```text
action → _pre_physics_step
  → 4 个物理子步：_apply_action → write_data_to_sim → sim.step → scene.update
  → _get_dones → _get_rewards → reset 失败或超时实例
  → _get_observations → 返回 obs reward done extras
```

set_joint_*_target 只写目标缓存，物理 step 才产生运动。物理为 200 Hz，策略为 50 Hz；隐式 PD 由 PhysX 求解，环境附加重力。actuator effort 估计不是隐式驱动实际约束力矩的直接读取。

| LAB 文件 | 职责 |
| --- | --- |
| [app_launcher.py](../../IsaacLab/source/isaaclab/isaaclab/app/app_launcher.py) | 启动运行时，必须先于仿真扩展导入 |
| [direct_rl_env.py](../../IsaacLab/source/isaaclab/isaaclab/envs/direct_rl_env.py) | step 和 reset 调度 |
| [interactive_scene.py](../../IsaacLab/source/isaaclab/isaaclab/scene/interactive_scene.py) | 场景、克隆和数据更新 |
| [articulation.py](../../IsaacLab/source/isaaclab/isaaclab/assets/articulation/articulation.py) | 关节与根状态、目标缓存 |
| [vecenv_wrapper.py](../../IsaacLab/source/isaaclab_rl/isaaclab_rl/rsl_rl/vecenv_wrapper.py) | TensorDict、done、timeout 和日志 |
| [rl_cfg.py](../../IsaacLab/source/isaaclab_rl/isaaclab_rl/rsl_rl/rl_cfg.py) | runner、网络和 PPO 配置结构 |

`physics_contract.py` 管 TGS 外部 effort 每内部迭代生效的 True 设置，不是人为平分重力。dt 数值对照需要固定策略和控制器更新周期，避免同时改变两个变量。

实际 RSL-RL 来自本工程二进制运行时，不是旧 Conda 同名库。actor 为 `27→256→128→64→6`，critic 为 `27→256→128→64→1`，隐藏激活 ELU。actor 产生高斯均值，训练使用可学习 std 采样，回放用均值；没有 tanh 的天然 [-1,1] 保证。

| RSL-RL 文件 | 先读入口 |
| --- | --- |
| runners/on_policy_runner.py | learn、save、load、get_inference_policy |
| modules/actor_critic.py | update_distribution、act、act_inference、evaluate |
| networks/mlp.py | 层和激活构建 |
| algorithms/ppo.py | act、process_env_step、compute_returns、update |
| storage/rollout_storage.py | add_transitions、compute_returns、mini_batch_generator |

每轮采集 `8192×48=393216` 条 transition，用 gamma=0.99、lam=0.95 计算 GAE 和 return，再执行 5 epoch、每遍 4 mini-batch 的更新。初始 std=0.2、entropy 系数 0.001、起始学习率 0.0003，学习率按 KL 自适应。PPO clip_param 约束概率比，不是电机限幅；梯度不会穿过 PhysX。

## 恢复 评估和持续优化

train 管配置、环境、wrapper、runner 和 learn。`training_state.py` 恢复优化器和学习率，`exploration.py` 管 std；车辆、动作、观测、求解器契约拒绝不匹配权重。当前训练完整策略，不冻结腿或只调轮头。

`auto_train_mine.py` 分发到 `joint_pd_optimization.py`，候选与控制组同源、有界单变量短训，再做独立多工况回放；明显跨任务退化则拒绝。未知故障停下查证，用户暂停单独记录为 `paused_user_request`，不自动恢复。

`evaluate_mine_policy.py` 冻结权重，在自动 reset 前记录故障，保存精确 obs/raw mean。标准矩阵为静止、前后 0.3/0.6 m/s、左右 0.3 rad/s 转向、0.28/0.32 m 高度，九工况三个种子。

`summarize_mine_trial.py` 使用 [验收参数](../../mine_model/config/tracking_acceptance.json)：非零目标相对误差 10%，零速绝对容差 0.025 m/s，零 yaw 0.025 rad/s，姿态 P95 2.5°，并检查存活及参考执行。零目标不能做百分比分母，能站不代表能走。

固定控制器、VMC 支撑、限位和数值收敛工具用于区分学习问题与动力学问题，仍保留。它们不是其他车型或额外环境，不应同时启动多份训练。

## 键盘 sim2sim 和部署

`play_keyboard.py` 优先选择最近优化任务已评估并保留的 best_checkpoint，不选最新但未评估或已淘汰的候选。W/S 给前后速度、A/D 给 yaw rate，Q/E 改高度终点并平滑送入策略；改变的是 command，不是直接电机动作。空格仅是跳跃占位，当前平地没有跳跃训练链。

MuJoCo 的 `mine_model.py` 转换资产，`core.py` 构造匹配 obs 并执行两种控制模式，`run.py` 回放、`keyboard.py` 接受指令，evaluate/compare 做跨仿真器评估。PD 和前馈合并后限矩，接口通过不等于全工况性能一致。见 [MuJoCo 说明](../sim2sim/README.md)。

`sim2real/wheelleg_deploy` 不依赖 LAB：policy 管冻结包，schema 管观测，targets 映射关节角/轮速，session 管序号及超时，protocol/transport 为离线模板。当前部署导出支持直接关节角策略。旧 LQR/VMC 下位机是标定参考，不等于已对齐新策略内环。

串口帧、零位、轴向、PD、前馈、真实限位、延迟和安全接管仍需统一。本轮不连接串口、不使能机器人。上位机只需推理依赖与匹配策略包，不搬仿真运行时；见 [部署说明](../../sim2real/README.md)。
